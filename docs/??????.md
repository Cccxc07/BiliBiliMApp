# 巨魔（TrollStore / TrollFools）注入指南

## 0. 先搞清楚链条

```
源码（本仓库）
   │  ① 编译 —— 需要 macOS + Xcode（本项目依赖 MonkeyDev）
   ▼
libBiliBiliMDDylib.dylib   ← 注入器要的就是这个文件
   │  ② 注入 —— TrollFools 在手机上完成
   ▼
哔哩哔哩（未加密 IPA，TrollStore 安装）
```

你手上已经有 ②（巨魔注入器），缺的是 ①。**注入器不能吃源码**，这是唯一的卡点。

## 1. 注入前必须准备两个东西

| 东西 | 要求 | 从哪来 |
| --- | --- | --- |
| **未加密的哔哩哔哩 IPA** | TrollStore 能装的包；App Store 直装的加密包注入后起不来 | 巨魔商店分发的 bili IPA，或自己用 dumpdecrypted 脱壳 |
| **libBiliBiliMDDylib.dylib** | arm64、iOS 13+ | 用本仓库编译（见 `BUILD.md`，或跑 `BiliBiliMD/Scripts/build-dylib.command`） |

**版本建议**：`8.41.0` 或 `8.76.0`。这两个版本有对应的倍速兼容 handler（硬编码偏移）；其它版本注入后建议在设置里把「默认播放速度」保持默认，别动倍速，否则偏移不对会崩。

## 2. TrollFools 注入步骤

1. 用 **TrollStore** 安装未加密的哔哩哔哩 IPA（不要用 App Store 版本）。
2. 打开 **TrollFools**（巨魔注入器）。
3. 在应用列表里找到「哔哩哔哩」，点进去。
4. 点「**注入**」（Inject），在文件选择器里选中 `libBiliBiliMDDylib.dylib`。
   - 如果找不到文件：先把 dylib 放到「文件」App 能访问的位置，例如 `我的 iPhone/Downloads/`，或用微信/QQ 传到手机再「用其他应用打开 → 存储到文件」。
5. 等待提示注入成功（TrollFools 会把 dylib 塞进 App 的 `Frameworks/` 并改写 `LC_LOAD_DYLIB`）。
6. **完全杀掉哔哩哔哩进程**（上滑卡片关掉），再重新打开。
7. 进入 `我的 → 设置`，滑到「版本 / 官网」那一组上方，应看到：
   - `底部栏-发布(+)`
   - `底部栏-会员购`
   - `我的-不常用服务`
   - `默认播放速度` / `关注页的默认版块`
   - `自动领取大会员福利`
   - `竖屏模式`
   - `首页搜索框-热词`
   - `搜索结果-相关搜索`
   - **`直播间-保留观看人数/醒目留言`** ← 本次新增，默认开

看到这一行就说明注入成功、代码生效。

## 3. 验证本次改动

1. 进任意直播间 → 顶部能看到**人气/观看人数**；
2. 找一条**醒目留言（SC）** → 卡片出现、带倒计时；
3. 广告仍在拦：收入面板、预约按钮、右上角活动入口、礼物动画、关注弹窗；
4. 把「直播间-保留观看人数/醒目留言」关掉 → 杀进程重启 → 人数和 SC 应消失（证明开关生效），再打开恢复。

## 4. 注入失败对照表

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| TrollFools 里找不到 App | 该 App 不是 TrollStore 安装的 | 用 TrollStore 重装该 IPA |
| 注入了但 App 一开就闪退 | 目标是加密包 / dylib 架构不对 | 换未加密 IPA；确认 dylib 是 arm64（`lipo -info` 看） |
| App 能开，设置页没有新项目 | dylib 没被加载 | TrollFools 里确认注入记录还在；换 Debug 版重编（`-framework LookinServer` 需要先装 Lookin）|
| 有设置项，但直播页人数/SC 还是没有 | 还有别的类参与渲染 | 见 `docs/CHANGES.md` 第 7 节，把候选类发我，我补守卫 |
| 改开关没反应 | 开关只在进程启动时读一次 | 杀进程重启 |
| 想撤销 | — | TrollFools 里对该 App 点「移除注入」；或卸载重装 IPA |

## 5. 没有 Mac 时怎么拿到 dylib

| 路径 | 说明 |
| --- | --- |
| **借/租 Mac** | 最稳。`BiliBiliMD/Scripts/build-dylib.command` 双击即可，只出 dylib，**不需要脱壳包**（不注入、不打包 IPA） |
| **GitHub Actions 云编译** | `.github/workflows/build-dylib.yml` 已写好，点一下跑，产物在 Artifacts 里下载。首次可能因 MonkeyDev 安装方式不同失败，把日志发我，我改 |
| **找有 Mac 的人代编** | 把整个文件夹发过去，对方装 MonkeyDev 后跑同一个脚本，1 分钟出 dylib |
| **项目群** | 作者 Telegram 群 `t.me/TouchWorldFuckAd`，里面通常有人能代编 |

## 6. 关于「不注入、直接换整包」

如果你不想用注入器，也可以走完整 IPA 路线（`BUILD-IPA.command`）：把 dylib 塞进 `bili-universal.app` 再重签。但 TrollStore 环境下用注入器更省事，且能保留官方包更新，推荐用注入。
